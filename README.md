## 🎯 Обзор

**Финансист.AI** — это профессиональное десктопное приложение для автоматизации финансового анализа. Программа принимает на вход документы в различных форматах (PDF, Excel, Word, текстовые выписки, архивы RAR/ZIP и др.), автоматически извлекает из них финансовые данные, классифицирует документы по типам и генерирует аналитические отчёты с визуализацией.

Ключевая особенность — интеграция с локальными нейросетями (LM Studio) для генерации развёрнутых ИИ-презентаций на основе извлечённых данных, что позволяет получать профессиональные финансовые отчёты без выхода в интернет.

## ⚡ Ключевые возможности

### 📄 Парсинг документов
- **Автоматическое извлечение текста** из 50+ форматов файлов
- **Распознавание транзакций** из банковских выписок (доходы/расходы, контрагенты, суммы, даты)
- **Извлечение финансовых метрик** из ОСВ, балансов, деклараций и отчётности
- **Поддержка архивов** — автоматическая распаковка RAR, ZIP, 7Z файлов
- **Обработка пакетов документов** — загрузка целых папок клиентов

### 🏷️ Классификация документов
Программа автоматически определяет тип документа по содержимому и имени файла:
- Банковские выписки (`BANK_STATEMENT`)
- Оборотно-сальдовые ведомости (`OSV`)
- Бухгалтерские балансы (`BALANCE_SHEET`)
- Договоры (`CONTRACT`)
- Накладные и ТТН (`DELIVERY_NOTE`)
- Налоговые декларации (`TAX_DECLARATION`)
- Счета-фактуры (`INVOICE`)
- Инвентаризационные описи (`INVENTORY`)
- Отчёты о продажах (`SALES_REPORT`)
- И другие типы

### 📊 Аналитическая панель
- **Визуализация данных** — графики и диаграммы на основе извлечённых транзакций
- **Сводка по доходам и расходам** с автоматическим расчётом итогов
- **Табличное представление** всех распознанных операций
- **Цветовая кодировка** доходов (зелёный) и расходов (красный)

### 🤖 Интеграция с ИИ
- **Подключение к LM Studio** для генерации отчётов через локальные LLM
- **Автообнаружение сервера LM Studio** с определением доступных моделей
- **Два режима генерации презентаций:**
  - Офлайн-шаблон (мгновенная генерация без ИИ)
  - ИИ-отчёт (развёрнутый анализ через нейросеть)
- **Полная конфиденциальность** — данные не покидают локальную сеть

### 📤 Экспорт отчётов
- **Excel (.xlsx)** — структурированный отчёт с транзакциями и метриками
- **Word (.docx)** — текстовый отчёт с форматированием
- **PowerPoint (.pptx)** — презентация для выступлений
- **PDF** — через встроенный экспорт

### 📁 Управление документами
- **Drag & Drop** загрузка файлов
- **Просмотр списка** загруженных документов с информацией о количестве операций
- **Очистка** всех загруженных данных одной кнопкой
- **Журнал операций (Log Viewer)** для отладки

### 💰 Ручной учёт капитала
- Добавление постоянных доходов (зарплата, аренда и т.д.)
- Учёт расходов и кредитов с процентными ставками
- Учёт активов (недвижимость, акции, транспорт, бизнес)

## 🚀 Установка и запуск

### Прerequisites
- **Node.js** 18+ 
- **npm** или **yarn**

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

### Запуск Electron-приложения
```bash
npm run electron:dev
```

### Сборка инсталлятора Windows
```bash
npm run electron:build:installer
```

### Сборка портативной версии
```bash
npm run electron:build:portable
```

Готовые файлы будут в папке `release/`:
- `Финансист.AI Setup 1.0.0.exe` — инсталлятор
- `Финансист.AI 1.0.0.exe` — портативная версия
