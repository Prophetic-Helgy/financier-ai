<h1 align="center">Финансист.AI</h1>

**Локальное десктоп-приложение финансового учёта и аналитики для Windows (x64).**
Electron + React. Все данные хранятся **только на вашем компьютере** (папка
`%APPDATA%\financier-ai`): ни сервер, ни облако, ни телеметрия.

## Сценарии

На первом экране выбирается профиль — он определяет доступные вкладки и расчёты:

| Профиль | Для кого |
|---|---|
| Физлицо | Личные финансы: доходы/расходы, бюджеты, валюты |
| Семья | Совместный учёт: локальные профили с ролями и видимостью категорий |
| Самозанятый / ИП | Доходы, НДФЛ (самозанятость), активы, кредиты |
| Селлер маркетплейсов | Калькуляторы маркетплейсов, аналитика продаж |
| МСБ | Учёт предприятия, мультивалютность, отчёты |
| Холдинги | Несколько юрлиц, межфирменные операции, консолидация |

## Возможности

- **Учёт** — локальная «книга»: операции, счета, категории; ручные записи и импорт.
- **Импорт выписок** — CSV/XLSX банков РФ (Сбер, Т-Банк, Альфа-Банк, ВТБ), экспорт 1С;
  архивы **ZIP и RAR**; повторы автоматически пропускаются (дедупликация).
- **OCR для сканов** — PDF-выписки без текстового слоя распознаются локально
  (tesseract.js, русский язык).
- **Мультивалютность** — RUB/USD/EUR, курсы ЦБ РФ, пересчёт в базовую валюту,
  курсовые разницы по месяцам.
- **Бюджеты** — план-факт по категориям, прогноз «к концу месяца», what-if.
- **Периоды** — закрытие/открытие месяца, корректирующие записи, MTD/YTD;
  в закрытый месяц импорт блокируется (только корректировки).
- **Профили и роли** — «владелец» / «наблюдатель», индивидуальные наборы категорий.
- **ИИ-категоризация** — эвристики + локальный LLM (LM Studio или любой
  OpenAI-совместимый endpoint, по умолчанию `127.0.0.1:1234`). Данные не покидают
  машину; без LLM работает эвристика.
- **Холдинг** — дерево юрлиц, автоматические межфирменные пары, elimination,
  консолидированный итог группы, журнал аудита (кто/когда/что, последние 500).
- **Аналитика и отчёты** — вкладки «Аналитика», «Таблица», «Презентация», «Отчёты»
  по загруженным документам.
- **Экспорт** — XLSX, DOCX, PPTX (PDF-экспорт нет).
- **Бэкапы** — автоматические копии в userData (5 штук, автовосстановление при
  повреждении файла) + ручной экспорт/импорт JSON.

## Чего в этой версии нет (честно)

- PDF-экспорт отчётов; архивы 7z; сетевой мультипользователь (только локальные профили).
- Стандартные МСФО/РСБУ отчётности: консолидация — собственный учётный метод
  (elimination межфирменных пар), не «бухгалтерский МСФО-пакет».
- Автообновление (electron-updater): обновление — загрузкой новой версии.

## Установка

Три равноценных артефакта (Windows x64):

| Артефакт (1.0.0) | Размер | Как пользоваться |
|---|---|---|
| `Финансист.AI Setup 1.0.0.exe` | 116,5 МБ | Установщик NSIS: выбор папки, ярлыки, «для всех/для текущего пользователя». Удаление через «Приложения» |
| `Финансист.AI 1.0.0.exe` | 116,2 МБ | Portable-файл: запустить, не устанавливая |
| `Финансист.AI Portable x64.zip` | 168,6 МБ | Тот же каталог приложения архивом: распаковать и запустить `Финансист.AI.exe` |

Все три используют **одну общую папку данных** `%APPDATA%\financier-ai` —
при переносе с portable на установленную версию данные сохраняются.

## Лицензия

Релиз распространяется в **открытом режиме**: бесплатно, полная функциональность,
без искусственных ограничений. Код программы — проприетарный.
Возможность платного режима (ключ, привязка к машине, онлайн/офлайн-активация)
спроектирована — см. внутренний документ `docs/PAYED_LICENSING.md`; в текущем
релизе не включена.

## Требования

- Windows 10/11 x64; ~400 МБ места на диске; 2+ ГБ ОЗУ.
- Для ИИ-категоризации (опционально): локальный LLM, например [LM Studio](https://lmstudio.ai),
  запущенный на `http://127.0.0.1:1234`.

## Разработка

```bash
npm install
npm run dev              # vite :3000 (только renderer, в браузере)
npm run electron:dev     # сборка + запуск Electron
npm run lint             # tsc --noEmit
npm run electron:build   # все артефакты (NSIS + portable) в release/
```

**Тесты** — 9 автономных tsx-сьютов, 262 проверки (без тест-фреймворка):

```bash
npx tsx test-bank-import.ts && npx tsx test-fx.ts && npx tsx test-budgets.ts \
  && npx tsx test-periods.ts && npx tsx test-users.ts && npx tsx test-ai-categorize.ts \
  && npx tsx test-ocr.ts && npx tsx test-consolidation.ts && npx tsx test-edge-cases.ts
```

Матрица тест-кейсов — `TEST_CASES.md`, известные ограничения — `BUGS.md`.

## Структура проекта

```
electron/main.cjs      главный процесс: окно, IPC store:*, автовосстановление .bak.1…5
src/
  pages/               Home (выбор профиля), Dashboard (вкладки)
  components/          LedgerView («Учёт»), SellerView, экспорт, загрузчик и др.
  lib/store/           модель и логика: schema, migrations, store, fx, budgets,
                       periods, consolidation, roles, audit, categorize
  lib/parsers/         парсеры выписок (Сбер/Т/Альфа/ВТБ, 1C) + ZIP/RAR
  lib/ocr/             распознавание скан-PDF (tesseract.js, rus)
  lib/                 export, cbrService (курсы ЦБ), llmIntegration, licensing, …
docs/ROADMAP.md        план разработки по фазам
test-*.ts              автосьюты (tsx)
```
