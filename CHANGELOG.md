### Security (2026-08-26, Фаза 2.4)
- **CSP** (Content-Security-Policy) в production-сборку: meta-тег в `index.html` через vite-плагин `inject-csp` (только `apply: 'build'`, dev-сервер не затрагивается). Политика: `default-src 'self'`, `object-src 'none'`, `base-uri 'self'`; `connect-src` разрешает http/https — для пользовательского endpoint LM Studio и курсов ЦБ.
- **`sandbox: true`** в webPreferences (electron/main.cjs) — рендерер без Node API; совместимость подтверждена (preload использует только contextBridge/ipcRenderer, в src нет require/process).
- **LogViewer**: monkey-patch `console.log/error/warn` теперь активен только в dev-режиме; в production поведение console библиотек не искажается.
- **FileUploader**: удалены все 33 отладочных `console.log` (включая логи, печатавшие превью содержимого файлов); `console.error` сохранены.

### Added (2026-08-28, Фаза 2.3 — калькуляторы «Селлера»)
- **Вкладка «Селлер» в профиле «Селлер маркетплейсов»** ([SellerView.tsx](src/components/SellerView.tsx)) — подключены два ранее неиспользуемых модуля (решение пользователя: подключить, а не удалять):
  - [sellerCalculators.ts](src/lib/sellerCalculators.ts): себестоимость товара (со структурой), продажная цена с целевой маржой, unit-экономика с учётом возвратов, точка безубыточности (объём/выручка + прибыль при 0.8×–1.5× объёма), ROI/ROMI рекламы (CPC/CVR/AOV/CPA), влияние скидки/акции (нужный рост объёма). Расчёт синхронный, обновляется при каждом изменении поля; при «переменных долях ≥ 100%» — предупреждение вместо цифр.
  - [marketplaceAnalytics.ts](src/lib/marketplaceAnalytics.ts): аналитика загруженных выписок по маркетплейсам (WB / Ozon / Я.Маркет / СберМаркет / Авито — по контрагентам и назначению), оценка комиссий по типовым ставкам, KPI селлера, подсказки по налогам.
- **Fixed**: `calculateSalePrice` игнорировал параметр `целеваяМаржа` — цена считалась с почти нулевой прибылью. Формула: `цена = фикс. расходы × (1 + маржа) / (1 − переменные доли)`; прибыль при такой цене = фикс. расходы × маржа. Smoke-проверки (себестоимость / цена / прибыль / ТБ / вырожденный случай) пройдены.
- Примечание: API-функции `fetchWBReport/fetchOzonReport/fetchYandexMarketReport` остаются не подключёнными — в приложении нет UI для API-ключей маркетплейсов (в README API-интеграцию не заявлять).

### Added (2026-08-28, Фаза 3.1 — импорт выписок банков РФ + архивы)

Фикстуры: `test-data/bank-statements/` (синтетические).

### Added (2026-08-28, Фаза 3.3 — мультивалютность)
- **Мультивалютность по-настоящему** ([fx.ts](src/lib/store/fx.ts)) — отказ от «всё в ₽»:
  - **схема v2** (миграция v1→v2 в [migrations.ts](src/lib/store/migrations.ts): у старых операций `currency = RUB`, `fxRates = []` — данные не теряются, backward-compatible);
  - операция несёт валюту (ISO 4217) = валюту счёта-назначения; ключ дедупликации теперь различает валюты (та же операция в ₽ и в $ — две операции);
  - курсы `FxRate` (₽ за 1 единицу); пересчёт в базовую (RUB) по **последнему курсу с датой ≤ даты операции**; нет курса → 1:1 + янтарный баннер «Нет курсов для валют: …»;
  - **ЦБ РФ**: онлайн-загрузка официального XML-справочника (история по любой дате) через IPC `fx:cbr` в main-процессе ([electron/main.cjs](electron/main.cjs) — у cbr.ru нет CORS для рендерера, Node-fetch не ограничен) + ручной ввод/удаление курсов, upsert по валюте+дате;
  - **курсовые разницы за месяц** (переоценка валютных остатков: остаток на курс начала/конца месяца минус поток) — строка на карточках «По месяцам»;
  - секция **«Счета»**: создание/удаление счетов с валютой (удаление счёта с операциями запрещено), селектор счёта-назначения в панели импорта (при >1 счёте);
  - итоги/баланс/месяцы — в базовой валюте, у валютных операций в журнале строка «≈ X ₽» по курсу на дату.
- **Smoke-тест** [test-fx.ts](test-fx.ts) (`npx tsx test-fx.ts`): 38 проверок — выбор курса по дате, пересчёт, «нет курса», курсовые разницы по ручному расчёту (1000 USD @80→84 + 300 USD @82→84 = 4600 ₽), слияние курсов ЦБ (замена/добавление/мусор), миграция v1→v2, импорт в USD-счёт + дедупликация по валюте. Проверено на живом ЦБ: 54 валюты, USD 28.02.2026 = 77.2736 (исторический запрос).
- Примечание: ДДС в аналитике документов (вкладка «Аналитика»/экспорт) остаётся в ₽ — это отдельная поверхность по загруженному документу, а не по хранилищу (follow-up). Тикер «курсы ЦБ» в футере (cbrService.ts, mirror) не тронут.
