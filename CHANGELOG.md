### Added (2026-08-26, Фаза 1 — хранилище и сущности учёта)
- **Финансовые данные теперь переживают перезапуск приложения** — JSON-файловое хранилище в userData Electron (`financier-store.json`), IPC `store:*` в [electron/main.cjs](electron/main.cjs):
  - атомарная запись (tmp+rename);
  - автоматические бэкапы `.bak.1…5` при каждом сохранении;
  - автовосстановление с бэкапа при повреждении основного файла;
  - ручной экспорт/восстановление JSON-бэкапа (диалоги сохранения/открытия).
- **Сущности учёта** ([src/lib/store/schema.ts](src/lib/store/schema.ts), schemaVersion=1, uuid-ID): Организация → Счёт (банк/карта/наличные, валюта), Контрагент, Категория, Транзакция, Бюджетная цель, Период.
- **«Импортировать в учёт»** — кнопка в левой панели: загруженные документы нормализуются в сущности; дедупликация по date+amount+контрагент+назначение (повторная загрузка той же выписки не создаёт дублей).
- **Вкладка «Учёт»** ([LedgerView.tsx](src/components/LedgerView.tsx)): итоги (операций/доходы/расходы/баланс), разбивка по месяцам, журнал операций (последние 200), бэкапы.
- **Цепочка миграций** ([migrations.ts](src/lib/store/migrations.ts)): `migrateStore()` — версионные, backward-compatible (v1 — стартовая версия).
- Ручные записи вкладки «Активы» (доходы/кредиты/активы) теперь персистентны: сохраняются в хранилище и восстанавливаются при старте.

### Added (2026-08-26, Фаза 2)
- **Вкладка «Активы» (ручной учёт) заработала**: формы доходов/кредитов/активов привязаны к state (value/onChange), добавлено удаление записей, исправлены опции схемы кредита (были скопированы «В месяц/Разово» вместо «Аннуитетный/Дифференцированный»). ⚠️ Данные пока не переживают перезапуск приложения — персистентность придёт с Фазой 1.
- **Экспорт в XLSX/DOCX/PPTX из вкладки «Экспорт»** — подключён существовавший, но не импортировавшийся никем [lib/export.ts](src/lib/export.ts):
  - Excel (.xlsx) — по листам на раздел: ОПиУ, Баланс (АКТИВ / ПАССИВ), ДДС, финансовые коэффициенты;
  - Word (.docx) — полный управленческий отчёт (сводка + все разделы) через markdown;
  - PowerPoint (.pptx) — слайд на раздел, длинные списки автоматически делятся на «(1/2), (2/2)».
  - Побочный фикс: в `exportMarkdownToWord` нумерованные списки ссылались на несуществующий numbering `myNumbering` — теперь определён в документе (LevelFormat.DECIMAL).
  - `lib/export.ts` грузится лениво (отдельный чанк ~622 КБ, gzip ~198 КБ) — тяжёлые зависимости xlsx/docx/pptxgenjs больше не в основном бандле.

### Added (2026-08-26, Фаза 2.5)

### Security (2026-08-26, Фаза 2.4)
- **CSP** (Content-Security-Policy) в production-сборку: meta-тег в `index.html` через vite-плагин `inject-csp` (только `apply: 'build'`, dev-сервер не затрагивается). Политика: `default-src 'self'`, `object-src 'none'`, `base-uri 'self'`; `connect-src` разрешает http/https — для пользовательского endpoint LM Studio и курсов ЦБ.
- **`sandbox: true`** в webPreferences (electron/main.cjs) — рендерер без Node API; совместимость подтверждена (preload использует только contextBridge/ipcRenderer, в src нет require/process).
- **LogViewer**: monkey-patch `console.log/error/warn` теперь активен только в dev-режиме; в production поведение console библиотек не искажается.
- **FileUploader**: удалены все 33 отладочных `console.log` (включая логи, печатавшие превью содержимого файлов); `console.error` сохранены.

### Removed (2026-08-26, Фаза 2.3 — мёртвый код)
