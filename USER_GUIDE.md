# USER_GUIDE.md — Финансист.AI, руководство пользователя

Версия 1.0.0 (2026-08-29). Всё, что описано здесь, действительно работает в этой версии.

## 1. Установка

Три равноценных способа (Windows x64):

1. **Установщик** — `Финансист.AI Setup 1.0.0.exe`:
   визард → выбор папки (по умолчанию `C:\Program Files\Fинансист.AI`) →
   «Для всех / Для текущего пользователя» → ярлыки на рабочий стол и в «Пуск».
   Удаление: «Параметры → Приложения» или `Uninstall Финансист.AI.exe` в папке.
2. **Portable-файл** — `Финансист.AI 1.0.0.exe`: запустить двойным щелчком.
3. **ZIP portable** — `Финансист.AI Portable x64.zip`: распаковать в любую папку,
   запустить `Финансист.AI.exe` внутри.

Все три способа используют **одну общую папку данных**:
`%APPDATA%\financier-ai` (то есть `C:\Users\<вы>\AppData\Roaming\financier-ai`).
Переход с portable на установленную версию (и обратно) ничего не теряет.

## 2. Первый запуск

1. Выберите **профиль**: Физлицо / Семья / Самозанятый-ИП / Селлер маркетплейсов / МСБ / Холдинги.
   Профиль выбирает, какие вкладки и расчёты показаны. Его можно сменить, вернувшись на главный экран.
2. Откройте вкладку **«Учёт»** — здесь хранятся ваши операции, счета и бюджеты.
3. Загрузите выписку (кнопка загрузки в панели слева) → **«Импортировать в учёт»**.

## 3. Импорт выписок

- **Форматы:** CSV, XLSX (и другие табличные) — выписки Сбер, Т-Банка, Альфа-Банка, ВТБ;
  экспорт 1С; текстовые/другие документы — для аналитики.
- **Архивы:** можно загрузить сразу ZIP или RAR с выписками внутри.
- **Сканированные PDF:** распознаются автоматически (OCR, русский язык),
  в итоге импорта появится пометка «OCR».
- **Повторная загрузка той же выписки безопасна**: дубликаты пропускаются
  (в результате — `added=0, skipped=N`).
- Невалидные строки (битые даты, пустые суммы) отбрасываются с подсчётом —
  в итог импорта попадает только корректное.

## 4. Вкладка «Учёт» — разделы (сверху вниз)

| Раздел | Что делает |
|---|---|
| **Профили (кто видит что)** | Локальные профили: владелец / наблюдатель; у наблюдателя — свой набор категорий |
| **Счета и категории** | Счета (RUB/USD/EUR), категории расходов/доходов |
| **Операции** | Журнал: импортные и ручные записи, «≈ X ₽» для валютных, кнопка ИИ-категоризации |
| **Бюджеты** | Лимиты по категориям: план/факт/остаток, прогноз к концу месяца, what-if |
| **Периоды** | Закрытие/открытие месяца, корректирующие записи (пометка «корр.»), MTD/YTD |
| **Валюты** | Курсы (в т.ч. автоматическое слияние с курсами ЦБ РФ), курсовые разницы по месяцам |
| **Организации (группа)** | Юрлица холдинга, дерево «родитель→дочерняя», межфирменные пары, **консолидация**, «Журнал аудита» |
| **Бэкапы** | «Экспорт бэкапа» (JSON-файл), «Из файла» (восстановление), «Авто-бэкап» |

## 5. Бюджеты

1. В разделе «Бюджеты» задайте лимит по категории на месяц.
2. Приложение покажет: план, факт, остаток, прогресс и **прогноз**
   («по текущему темпу к концу месяца будет …»).
3. What-if: изменение лимита мгновенно пересчитывает прогноз.

## 6. Периоды (закрытие месяца)

- «Закрыть месяц» — импорт в закрытый месяц блокируется; изменения возможны
  только **корректирующей записью** (пометка «корр.», учитывается в итогах).
- «Открыть месяц» — импорт снова проходит.
- MTD/YTD считаются автоматически; корректировки не ломают итог.

## 7. Валюты

- Счета могут быть в RUB, USD, EUR. Все итоги — в базовой валюте (RUB).
- Курсы подтягиваются из истории ЦБ РФ; для даты без курса — 1:1 и
  янтарное предупреждение (без потери операции).
- Курсовые разницы видны в «По месяцам».

## 8. Профили (семейный / совместный сценарий)

- Профиль «Наблюдатель» видит только операции из своих категорий (регистр
  имени не важен) и итоги по этому срезу.
- Управление данными (восстановление, удаление юрлиц) — только у владельца.
- Это **локальные** профили одного компьютера, не сетевая синхронизация.

## 9. Холдинг

1. «Организации (группа)” → добавьте юрлица, укажите родительское (циклы
   исключены: своё имя из списка родителей убирается).
2. Расход у A на контрагента B и встречный доход у B той же суммы —
   **межфирменная пара**: погашается и исключается из итога группы
   (строка «Межфирм.»).
3. Консолидированный итог группы = сумма юрлиц минус погашенные пары.
   Не погашенные односторонние операции показываются с янтарным флагом —
   книги сходятся/не сходятся видно сразу.
4. «Журнал аудита» — последние 500 изменений: кто (профиль), когда, что, детали.

## 10. ИИ-категоризация

- Кнопка «ИИ (LM Studio)» в «Операциях» предлагает категории для
  некатегоризированных операций.
- Нужен локальный LLM: [LM Studio](https://lmstudio.ai) (или любой сервер с
  OpenAI-совместимым API) на `http://127.0.0.1:1234`.
- Если LLM не запущен — понятная подсказка с endpoint, краха нет;
  работает эвристическая категоризация (без LLM вообще).
- Данные операций отправляются **только на ваш локальный** endpoint.

## 11. Бэкап и восстановление

- **Авто:** при каждом изменении данных в `%APPDATA%\financier-ai`
  держатся 5 последовательных копий (`.bak.1…5`); при повреждении основного
  файла приложение восстанавливается автоматически.
- **Ручной:** «Экспорт бэкапа» — JSON-файл всех данных; «Из файла» —
  восстановление из него (роль владельца); каждое восстановление —
  запись в журнале аудита.
- Рекомендация: периодически выгружать ручной бэкап во внешнее место.

## 12. Где лежат данные и приватность

- Всё: `%APPDATA%\financier-ai` (файл данных + бэкапы + настройки LLM).
- Приложение не имеет сервера, не шлёт данные в интернет.
  Единственное сетевое обращение — ваш локальный LLM-сервер (127.0.0.1).
- Перенос на другой компьютер: скопировать папку `%APPDATA%\financier-ai`
  (приложение должно быть закрыто).

## 13. Экспорт отчётов

Вкладка «Экспорт»: **XLSX, DOCX, PPTX** по загруженным документам/аналитике.
PDF-экспорт в этой версии отсутствует.

## 14. Лицензия

Релиз 1.0.0 — **открытый режим**: бесплатно, полная функциональность,
без искусственных ограничений. Строка о режиме видна в шапке вкладки «Учёт».

## 15. FAQ

**В: Приложение требует интернет?**
О: Нет. Работает полностью офлайн. Курсы ЦБ подтягиваются из локальной истории;
LLM — только если запущен у вас на машине.

**В: Можно ли пользоваться portable-версией и установленной одновременно?**
О: Да, данные общие — но не открывайте одну и ту же папку данных
одновременно в двух запущенных копиях (риск перезаписи).

**В: Забыл закрыть месяц, а теперь он «не редактируется»**
О: Это защита от случайных правок: либо откройте месяц, либо внесите
корректирующую запись (пометка «корр.»).

**В: Операция в валюте, курса нет — что делать?**
О: Ничего страшного: учтена по 1:1 с предупреждением; когда курс появится
(обновите «Валюты»), итоги пересчитаются.

**В: Как удалить юрлицо?**
О: В «Организациях» — только у владельца и только если у него нет операций
и не назначено дочерних (иначе — переназначьте родителя/перенесите операции).

**В: OCR распознаёт плохо**
О: OCR локальный (tesseract.js): лучше всего работает с чёткими сканами
PDF. Для табличных выписок надёжнее дать банку CSV/XLSX.
